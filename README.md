# vaultmime

Vault encode/decode helpers for mime payloads in pipelines.

**Site:** https://theworker02.github.io/vaultmime/

## Install / run

```bash
git clone https://github.com/theworker02/vaultmime.git
cd vaultmime
node src/cli.js
node --test
```
