Vault encode/decode helpers for mime payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/vaultmime.git
cd vaultmime
node src/cli.js --help
node --test
